El Misterio del Asesinato en SQL

¿Puedes descubrir quién lo hizo?

¡Ha habido un asesinato en SQL City! El Misterio del Asesinato en SQL está diseñado tanto para ser una lección autoguiada para aprender conceptos y comandos de SQL como un juego divertido para que usuarios experimentados de SQL resuelvan un crimen intrigante.

¿Nuevo en SQL?

Este ejercicio está pensado más como una forma de practicar habilidades de SQL que como un tutorial completo. Si nunca usaste SQL, probá el tutorial guiado. Si realmente querés aprender mucho sobre SQL, tal vez prefieras un tutorial completo como Select Star SQL.

Si ya te sentís cómodo con SQL, podés ir directo abajo!

Sabuesos de SQL experimentados, empiecen acá

Ha ocurrido un crimen y el detective necesita tu ayuda. El detective te dio el reporte de la escena del crimen, pero de algún modo lo perdiste. Recordás vagamente que el crimen fue un ​asesinato​ que ocurrió en algún momento del 15 de enero de 2018​ y que tuvo lugar en ​SQL City​. Empezá recuperando el reporte correspondiente de la base de datos del departamento de policía.

Explorando la estructura de la base de datos

Los usuarios experimentados de SQL a menudo pueden usar consultas para inferir la estructura de una base de datos. Pero cada sistema de bases de datos maneja esta información de forma distinta. El Misterio del Asesinato en SQL está construido con SQLite. Usá este comando SQL para encontrar las tablas de la base de datos del misterio.

Además de conocer los nombres de las tablas, necesitás saber cómo está estructurada cada una. La forma de hacerlo también depende de la tecnología de base de datos que uses. Así se hace con SQLite.

¡El resto depende de vos!
